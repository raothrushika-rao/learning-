🐛 COMMON ISSUES & FIXES

Port already in use (5000 or 3000):
  lsof -i :5000
  kill -9 <PID>

Database issues:
  cd backend
  rm instyle_hub.db
  npm run prisma:migrate -- --name init
  npm run seed

Module not found:
  cd backend
  npm install

Page won't load:
  1. Hard refresh: Ctrl+Shift+R
  2. Check F12 console (right-click → Inspect)
  3. Check both servers running
